# BattleStation TV Changelog

This document records BattleStation TV releases separately from the original IPTVMac project.

## Version 2.5.0 - Build 8

### Automatic Update System

Release status: Prepared for publication.

### Added

- Integrated GitHub-based update checking.
- Dedicated update management interface.
- Release information and version comparison.
- Update download workflow.
- Downloaded package checksum verification.
- Platform-specific update installation handling.
- Update notification and preference controls.

### Platform Distribution

- Windows x64 installer.
- Android ARM64 and x86-64 APK.
- SHA-256 package checksum files.

### Security and Distribution

- Android release signing.
- Application-specific package identity.
- Separate update package identification.
- Preservation of original GPLv3 attribution and licensing.

### Known Limitations

- Public automatic update installation requires end-to-end verification.
- Windows installation packages are not currently digitally signed.
- Android TV and Google TV compatibility may vary by device.
- Some older operating system configurations require further testing.
- Complete regression testing remains in progress.
