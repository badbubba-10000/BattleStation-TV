# BattleStation TV 2.5.0 - Build 8

## Automatic Update System

### Release highlights

- GitHub-based application update checking.
- Manual and configurable scheduled update checks.
- Update notifications and download controls.
- Customizable appearance and dashboard layouts.
- Optional cloud synchronization for supported preferences.
- Windows installation and uninstallation options.
- Android support for compatible phones, tablets and TV devices.

## Important information

This application does not provide IPTV subscriptions,
channels, movies or television series.

Users must supply their own authorized media sources.

The Windows installer is not digitally signed and may
display a Windows SmartScreen warning.

The application is free and contains no developer-operated
advertising or subscription charges.

Optional cloud synchronization uses Firebase services.
IPTV account credentials are excluded from preference sync
by the application.
