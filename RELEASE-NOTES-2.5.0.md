## System Requirements

Windows installer minimum: Windows 10 build 17763.

Windows 11 is recommended.

Android minimum: Android 8.0 Oreo, API 26.

Supported Android architectures: ARM64 and x86-64.

See SYSTEM-REQUIREMENTS.md for additional information.

## Security and Compatibility

Android packages use application-specific release signing.

Windows installers are not currently digitally signed by a trusted Windows publisher.

Verify package checksums before installation.

## Known Limitations

- End-to-end public update testing remains outstanding.
- Complete regression verification remains in progress.
- Compatibility varies by device and media provider.
- Older operating systems require additional runtime verification.
