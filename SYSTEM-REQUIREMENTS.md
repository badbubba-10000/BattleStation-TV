# BattleStation TV System Requirements

Version 2.5.0 - Build 8

## Windows

| Component | Minimum target | Recommended |
|---|---|---|
| Operating system | Windows 10 version 1809 | Windows 11 |
| Architecture | x64 | x64 |
| Processor | Dual-core | Quad-core or better |
| Memory | 4 GB RAM | 8 GB RAM or more |
| Available storage | 500 MB | 2 GB or more |
| Display resolution | 1280 x 720 | 1920 x 1080 or higher |
| Graphics | DirectX 11 compatible | Hardware video decoding |
| Internet connection | 5 Mbps | 25 Mbps or faster |

The Windows installer requires Windows build 17763 or newer.

This is the installer-defined minimum, not a guarantee of application compatibility on every older Windows version.

Windows 11 is recommended.

## Android

| Component | Minimum target | Recommended |
|---|---|---|
| Operating system | Android 8.0 Oreo | Android 11 or newer |
| API level | 26 | 30 or higher |
| Architecture | ARM64 or x86-64 | ARM64 |
| Processor | Dual-core | Quad-core or better |
| Memory | 2 GB RAM | 4 GB RAM or more |
| Available storage | 500 MB | 2 GB or more |
| Video decoding | H.264 support | Hardware H.264/H.265 decoding |
| Internet connection | 5 Mbps | 25 Mbps or faster |

## Android TV and Google TV

Compatible devices require a supported Android version and 64-bit application architecture.

A 64-bit processor does not necessarily mean that the device runs a 64-bit Android operating system.

Devices running a 32-bit Android operating system cannot install the current APK.

## Storage Considerations

Additional storage is required for downloaded movies, television episodes, DVR recordings, program guide data, artwork, and cached media information.

Actual storage requirements depend on usage.

## Internet Considerations

Streaming requirements depend on resolution, bitrate, codec, provider performance, and network reliability.

Higher-resolution streams may require considerably more bandwidth.

## Unsupported Platforms

- Windows 7
- Windows 8 and 8.1
- Windows 32-bit
- Android versions below 8.0
- Android 32-bit
- Roku
- Apple platforms

## Verification Status

The Android minimum API level and supported APK architectures are verified build requirements.

The Windows minimum build is verified from the installer configuration.

Processor, memory, storage, graphics, and network recommendations are provisional estimates rather than measured minimum hardware benchmarks.

Compatibility with individual devices may vary.
