# BattleStation TV Privacy Information

## Overview

BattleStation TV is designed without developer-operated advertising or usage analytics.

The application uses network services where required for user-selected functionality.

## IPTV Providers

The application communicates with IPTV providers configured by the user.

Providers may receive information required to authenticate accounts, retrieve media information, and deliver streams.

Provider privacy practices are controlled by the individual provider.

BattleStation TV does not sell or provide IPTV subscriptions.

## Local Application Data

The application may store information locally, including:

- Application preferences
- Appearance settings
- IPTV account information
- Favorites and viewing history
- Program guide information
- Cached artwork
- Downloads and recordings

Storage mechanisms vary by data type and platform.

Users should protect access to their devices and should not assume that all locally stored information is encrypted.

## Optional Cloud Functionality

Optional BattleStation TV account and cloud theme backup functionality uses Firebase services.

Cloud operations may involve:

- Account email addresses
- Authentication information handled by Firebase
- User identifiers
- Theme and customization backup data

IPTV credentials are intended to remain local and are not intended to be included in cloud theme backups.

Cloud backup functionality requires an internet connection.

## Automatic Updates

BattleStation TV communicates with GitHub to check for application releases and download update packages when requested.

These requests may disclose ordinary network information, such as an IP address, to GitHub and associated delivery infrastructure.

## Third-Party Services

The application may communicate with:

- User-configured IPTV providers
- Firebase authentication and cloud storage services
- GitHub release and download services
- Media and artwork services where used by supported features

Third-party services operate under their respective privacy policies.

## Advertising and Analytics

BattleStation TV is designed without developer-operated advertising systems or usage analytics.

Third-party providers and infrastructure may independently process information necessary to deliver their services.

## Data Removal

Users may remove local application data through supported application or operating system controls.

Cloud backup deletion is separate from local data removal.

Uninstalling the application does not necessarily delete associated cloud account information.

## Security

Never disclose IPTV credentials, account passwords, authentication tokens, or other sensitive information in public GitHub issues.

No software or network service can guarantee absolute security.

## Changes

This document describes the intended privacy behavior of BattleStation TV version 2.5.0.

It may be updated as application features and data-handling practices change.
